如何创建令牌 / How to create a token
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Expiration: 90 days. Repository access: Only select repositories → mingde-chinese.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy the token (github_pat_…), paste it above and press Use.
